-------------------------------------

Fix and candidate check
-----------------------
Patch kodi-9999-yblod-06-menu-target.patch recreates the GUI framebuffer after
resetting native playback at the handoff to a DV menu. It invalidates the old
target dimensions, clean flag and raster-ready flag so the next GUI render
allocates a fresh target instead of reusing the movie-shared image.
It does not alter movie reconstruction, packing math, menu colour settings,
or deliberately toggle the HDMI DV signal off/on.

The incremental Kodi build passed; normal CMake installation removed its build
RPATH. On the same VM, the candidate played 1917 from 08:00 and stopped with
DV menus ON; the user confirmed the menu was normal. The log retained DV
signalling while returning from 23.976 Hz movie timing to the 4K60 menu.
A further menus-OFF play/stop check restored ordinary signalling and closed
the native renderer without a reported transition error. No new movie-pixel
accuracy or GPU execution-time suite was run for this target-lifetime change.

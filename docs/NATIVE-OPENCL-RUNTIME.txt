Native renderer OpenCL dependencies

The native C/OpenCL renderer requires a loader, Intel's GPU runtime and its
compiler, in addition to the existing Mesa, VAAPI and Intel media-driver stack.
The media driver alone cannot execute reconstruction kernels.

Pinned packages
opencl-headers             2025.07.22       Khronos source archive
opencl-icd-loader          2025.07.22       Khronos source archive
intel-opencl-runtime      26.05.37020.3     Intel upstream binary package
intel-igc-core-runtime    2.28.4/build20760 Intel upstream binary package
intel-igc-opencl-runtime  2.28.4/build20760 Intel upstream binary package

Each recipe pins and verifies its input SHA256. The loader is cross-compiled
with the LibreELEC toolchain. The Intel runtime/compiler recipes install the
upstream x86_64 binaries; they do not claim to build those binaries locally.
They retain the supplied copyright/combined compiler notices. System libc,
libstdc++, Mesa, libva and gmmlib are not replaced with distribution copies.

The IGC release identifies its LLVM16, OpenCL-Clang, SPIR-V translator/tools
and vc-intrinsics revisions. Use those pins when rebuilding upstream IGC;
substituting the LibreELEC tree's newer LLVM is not an equivalent rebuild.

Packaging checks completed
- All three Intel binary archives match the upstream release checksums.
- The actual unpack/install recipe functions were exercised in staging.
- The Khronos loader cross-build and install succeed with the LibreELEC SDK.
- On an Intel N150, both general and specialized VAAPI-imported surface suites
  pass with the packaged loader and Intel runtime/compiler: 12 cases and
  208896 exact component comparisons per suite, zero differences. Pending
  frame identity, metadata rejection and sample-error recovery checks pass.
- These checks exclude the older development compiler library directory from
  library lookup and disable the persistent compiler cache.

These are dependency/package and GPU-compute checks, not qualification of a
complete LibreELEC image, every Intel GPU, HDMI output or playback performance.
The recipes are not automatically enabled for Kodi by this dependency change.

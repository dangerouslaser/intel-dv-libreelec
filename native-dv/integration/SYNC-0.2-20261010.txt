Native engine synchronization with YBLOD 0.2

Scope
Shared source port, not a new LibreELEC image or default-engine switch.
Engine src/ and tests match the released YBLOD 0.2 implementation.
The fork retains its pinned Kodi/CB1 base and explicit native-adapter selection.
No YBLOD-specific QMS/menu integration or base resync is imported.

Included
- Existing pending VAAPI live-10-bit and ActiveAE display-loss recovery fixes.
- Actual decoded frame rate for live startup, avoiding a duplicate live MPEG-TS
  open, and audio preroll based on buffered duration plus 100 ms headroom.
- Level 5 active-area handling while compositing overlays.
- GUI pixel cache, transparent reads, Home raster reuse and GUI revision reuse.
- Bounded movie-only asynchronous packing; asynchronous overlays remain OFF.
- Native adapter display coordination and GUI redraw fixes.
